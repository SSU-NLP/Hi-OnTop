# v4.2.4-exp — DSE-BERT 가 δ_model (RNN slot) 자리 대체

`src/hi_ontop/sem_core_v424_exp.py` · 2026-05-21 · **exp suffix**

## 한 줄

[[v4.1.1]] 의 식 구조 (`δ_eff² = η·δ_adj² + (1−η)·δ_model²`) 그대로
유지하되, **δ_model 의 산출처를 학습형 RNN PE 에서 frozen DSE-BERT 의
causal-window PE 로 교체**. δ_prev/δ_ctx (mpnet) 는 v4.1.1 그대로.

## 동기 — v4.1.1 의 "빈 RNN slot" 채우기

v4.1.1 는 SEM2 의 `LinearEvent` 학습형 dynamics 를 RNN 으로 구현했으나,
η-ablation (decision-log 2026-05-18) 에서 RNN 이 무용~유해로 판정되어
**default η=1 → RNN 자동 skip** 상태. δ_model slot 자체는 식 안에
있지만 weight 0 으로 무시.

codex 2026-05-18 (`P2`): "frozen-pretrained-f 제안 → 현 A3 유지, C
천장측정 후 재검토". v4.2.4-exp 가 그 P2 후속 후보의 직접 실현.

## 알고리즘 (수학 정의)

```
mpnet 채널 (v4.1.1 그대로):
  δ_prev(t)  = 1 − cos_mpnet(s_topic[t-1], s_topic[t])
  c_topic[t-1] = Σ_{i=1..m} ρ^{i-1} · s_topic[t-i]
  δ_ctx(t)   = 1 − cos_mpnet(c_topic[t-1], s_topic[t])
  δ_adj(t)   = a·δ_prev + (1−a)·δ_ctx                     # m=2, ρ=0.7, a=0.5

DSE 채널 (★ RNN 자리 대체):
  δ_prev_dse(t)  = 1 − cos_DSE(s_dse[t-1], s_dse[t])
  c_dse[t-1]     = Σ_{i=1..m_dse} ρ_dse^{i-1} · s_dse[t-i]
  δ_ctx_dse(t)   = 1 − cos_DSE(c_dse[t-1], s_dse[t])
  δ_model(t)     = a_dse·δ_prev_dse + (1−a_dse)·δ_ctx_dse  # m_dse=2, ρ_dse=0.5, a_dse=0.0

Blend (v4.1.1 식 그대로):
  δ_eff(t)² = η·δ_adj(t)² + (1−η)·δ_model(t)²
  boundary ⇔ δ_eff < δ* = 0.5594                           # mpnet TIAGE-train δ*
```

DSE channel HP 는 v4.2.2 TIAGE-train calibration (DSE encoder best:
m=2, ρ=0.5, a=0.0). mpnet δ\* (0.5594) 은 그대로.

⚠ **δ_adj 와 δ_model 의 raw scale 이 다름**: mpnet δ ≈ 0.4~0.6,
DSE δ ≈ 0.3~0.5. η blend 가 raw 로 일어나서 effective weight 가 η 와
정확히 일치 안 함. mixed δ_eff 는 일반적으로 δ_adj 보다 약간 작음
(DSE δ 가 작으니까) → 같은 δ\* 적용 시 **boundary 덜 트리거** = 과분절
완화 효과.

## v4.2.3-exp 와의 차이 (왜 또 다른 변형)

| | v4.2.3-exp | **v4.2.4-exp** |
|---|---|---|
| 구조 | dual-channel **calibrated energy** `r = √(w_t·z_t² + w_f·z_f²)` | v4.1.1 의 `η·δ_adj² + (1−η)·δ_model²` 식 그대로 |
| Threshold normalization | 두 채널 각자 δ\* 로 z-score | 안 함 (raw δ scale) |
| Internal δ\* | 1.0 (강제) | 0.5594 (v4.1.1 그대로) |
| SEM2 매핑 | "calibrated two-feature residual" | **"frozen-pretrained learned-dynamics"** (P2 후속) |
| mpnet 의 역할 | z_topic (z-score 후 channel) | **identity-PE 본체** (변경 0) |
| DSE 의 역할 | z_flow (z-score 후 channel) | **RNN slot 의 frozen 대체** |

→ v4.2.4 는 mpnet 의 v4.1.1 본체를 손대지 않고 RNN slot 만 frozen 으로
채우는 형태. SEM2 정신상 **더 자연스러운** 도입.

## SEM 계승 3-step (PASS, conditional)

1. **SEM2 에 있나?** `LinearEvent` 의 dynamics slot 자체는 SEM2 에 존재
   (learned-f). v4.1.1 가 그 자리에 RNN 을 넣었던 것. v4.2.4 는 같은
   slot 에 frozen pretrained encoder (DSE) 를 넣음. **새 mechanism slot
   도입이 아니라 기존 slot 의 구현 교체**.
2. **충돌?** 없음. sCRP / Bayes / local-MAP / prior-corrected B0 모두
   변경 0. δ_eff 식 (η blend) 도 v4.1.1 그대로. likelihood `L(δ) =
   −δ²/(2σδ²)` 그대로 (mpnet δ\* scale).
3. **decision-log**: 2026-05-21 entry.

⚠ Framing: v4.2.4 는 **"RNN 학습 환경 부족 → frozen 대체"** 의 자연스러운
해석. SEM 의 "scene dynamics 가 있다" 라는 가정 자체는 보존. RNN 이라는
*구현 선택* 의 약점 (per-topic 저표본 학습) 을 frozen pretrained 으로
우회.

⚠ Zacks 2007 EST 의 multi-feature PE 는 *개념적* 연결로만 사용 (성능
근거로 인용 금지). v4.2.4 의 핵심 정당화는 SEM2 의 frozen-f 대체.

## 운영 (use_rnn 강제 False)

- `super().__init__(use_rnn=False, ...)` → parent 의 RNN compute /
  training 회피.
- `_uses_rnn()` 은 항상 False 반환 (`use_rnn=False` 라서).
- 대신 `_delta_eff` 를 fully override 해서 cached DSE δ_model 사용.
- Caller 는 `assign_pair(s_topic, s_dse)` 사용 (단일 벡터 `assign` 은
  `NotImplementedError`).
- parent 의 모든 topic state (sCRP counts, f0 centroids, restart logic,
  σ² samples 등) 는 s_topic (mpnet) 으로 운영. s_dse 는 `_prev_s_dse` /
  `_recent_dse` 로 분리 보관.

## 해석

### Dialseg711 의 천장 돌파 (가장 큰 발견)

```
v4.1.1 @TIAGE-cfg        (mpnet only):       0.5897
v4.1.1 @oracle-δ*        (test-tuned 상한):  0.629
v4.2.4 @η=0.5 (TIAGE-cfg, test 누설 없음):   0.6480  ← oracle 보다 +1.9pp 위
```

v4.1.1.md 에서 명시했던 **"유사도 천장 0.590"** 가설 약화. DSE 가
정형 topic-shift 정보를 mpnet 보다 더 잘 잡는다는 증거.

### Mean Score 에서 v4.1.1 첫 superiority

η=0.75 의 mean 0.5084 가 v4.1.1 의 0.5068 보다 +0.16pp. 단일 trial 의
미세 차이라 noise 가능성 있으나 v4.2.x 라인에서 **mean Score 우위 첫
사례**.

### SuperDialseg 의 일관 회귀

DSE 가 어떤 η 에서도 SuperDialseg 에 해로움. 이유 가설:
- SuperDialseg 의 GT boundary 가 상대적으로 많음 (recall 중요)
- DSE δ_model 이 raw scale 더 작음 → mixed δ_eff 가 δ_adj 보다 작음 →
  같은 δ\* 에서 boundary 덜 트리거 = under-segmentation
- → recall 떨어지고 F1 큰 폭 하락 (η=0.5 superseg F1 0.4323 → 0.3151)

### 메커니즘 (mechanism caveat)

η < 1 의 효과는 **두 가지 섞임**:
1. **DSE 의 dialogue-flow 정보 추가** (가설된 효과)
2. **δ_eff scale 축소로 boundary 완화** (calibration 부수효과)

(2) 의 효과를 분리하려면 v4.2.4 의 mixed δ_eff scale 에 맞는 새 δ\*
재calibration 필요 (`scripts/calibrate_v424_*.py` 후속).

### 메커니즘 — F1-best ≠ Score-best (v4.1.1.md 가 미리 경고한 패턴)

- F1-best δ\* 는 recall+precision 최적화 → boundary 더 자주 트리거
- Score = 0.5·F1 + 0.25·(1-Pk) + 0.25·(1-WD) — Pk/WD 도 weight 있음
- boundary 늘면 Pk/WD 악화 → Score 떨어짐
- → F1-best δ\* 가 Score 에선 sub-optimal
- prior δ\*=0.5594 (mpnet 의 TIAGE-train F1-best) 가 Dialseg711 mixed
  signal 에는 우연히 Score-best 에 가까웠던 것. re-cal 로 그 우연 깨짐.

### 결정 — exp 유지, v4.1.1 default 유지

- mean Score 어떤 (η, δ\*) 조합에서도 v4.1.1 못 이김
- Dialseg711 "oracle 천장 돌파" 는 calibration luck, 실제로는 v4.1.1
  baseline 보다 worse
- v4.2.4-exp 코드는 보존 — Score-best δ\* sweep / dataset-aware δ\* /
  joint HP grid / CSM 학습 후 CSM-as-encoder (v4.2.5 후보) 등 후속
  연구의 출발점

### 미해결

1. **Score-best δ\* sweep**: F1-best 대신 Score 직접 최대화하는 δ\*
   train 에서 찾으면 결과 또 달라질 가능성. 단 v4.1.1.md 의 일관된 정책
   ("train calibration = F1-best") 을 따르려면 본 negative 가 정답.
2. **superseg-train δ\* (92k turn)**: 본 calibration 은 validation 사용.
   train 사용 시 결과 다를 가능성 (GPU 필요).
3. **Multi-seed variance** 미측정.
4. **DSE channel HP joint sweep** 안 함.

## 한계 / 검증 미해결

- **δ\* re-calibration 미실행** (위 메커니즘 caveat).
- **단일 seed**, variance 미측정.
- **SuperDialseg 회귀 원인 분리 안 됨** — under-segmentation by DSE soft
  blending vs DSE channel intrinsically uninformative on superseg domain.
- **TIAGE-test 는 in-domain 측정** (calibration overlap), v4.1.1.md 와
  같은 disclosure 적용.
- **DSE channel HP (m=2, ρ=0.5, a=0.0)** 는 v4.2.2 의 DSE single-channel
  best. v4.2.4 의 blend 안에서는 다른 best 일 가능성 (joint
  calibration 미수행).
- **F1 가 대체로 하락** (Score 는 Pk/WD 의 hard cut 완화로 오름). F1
  primary 면 다른 결론 가능.
- **`max_seq_length=512`** truncation 영향 미검증.
- **generic opener / short turn bucket 분석** 미수행.
