# v3.3.4 — PE threshold 의 per-topic variance calibration

CLI method: `hi-ontop-full-v3.3.4`. Segmenter class: `HiOnTopSegmenterV334` (구현 2026-05-09).

## 한 줄

v3.3.2 의 global hard PE threshold 를 제거하거나 약화하고, topic별 cosine PE 분산 $\sigma_k^2$ 를 EMA 로 추정해 likelihood 를 $-\mathrm{PE}^2/(2\sigma_k^2)$ 로 calibration 한다. 좁은 topic 은 작은 PE 변화에도 surprise 가 크고, 넓은 topic 은 같은 PE 를 더 관대하게 받아들이도록 한다.

## 동기

v3.3.2 까지는 fresh topic 이 $\tau \cdot \text{cos\_threshold}$ 로 경쟁하고, surprise 는 `max_k cos(s, ŝ_k) < 1 - pe_threshold` hard rule 로 처리된다. 그러나 cosine PE 분포는 topic 별로 다를 가능성이 높다.

- 좁은 주제: 예측 embedding 이 안정적이고 PE 분산이 작음.
- 넓은 주제: 같은 label 안에서도 turn 의 의미 폭이 넓어 PE 분산이 큼.

global threshold 는 두 경우를 같은 기준으로 자른다. v3.3.4 는 SEM 의 Gaussian PE 정신에 맞춰 "오차의 절대값" 이 아니라 "그 topic 에서 얼마나 이례적인 오차인가" 를 score 에 넣는다.

## EMA variance 업데이트

각 topic $k$ 는 scalar cosine PE 분산 상태를 유지한다.

$\mathrm{PE}_{n,k} = 1 - \cos(s_n, \hat{s}_{n,k})$

할당된 topic $k^\*$ 에 대해서만 online update 한다.

$\mu^{\mathrm{PE}}_k \leftarrow (1-\rho)\mu^{\mathrm{PE}}_k + \rho \mathrm{PE}_{n,k}$

$v_k \leftarrow (1-\rho)v_k + \rho(\mathrm{PE}_{n,k} - \mu^{\mathrm{PE}}_{k,\text{old}})(\mathrm{PE}_{n,k} - \mu^{\mathrm{PE}}_k)$

$\sigma_k^2 = \max(v_k, \sigma_{\min}^2)$

여기서 $\rho$ 는 `pe_var_decay` 로부터 정한다.

$\rho = 1 - \text{pe\_var\_decay}$

기본값은 `pe_var_decay=0.95` 이므로 최근 약 20개 할당을 반영한다.

## 새 likelihood

v3.3.2 repeat likelihood 는 다음과 같았다.

$\log p(s_n \mid k) \propto \tau \cos(s_n, \hat{s}_{n,k})$

fresh topic 은 다음 상수로 경쟁했다.

$\log p(s_n \mid K+1) \propto \tau \cdot \text{cos\_threshold}$

v3.3.4 는 cosine 을 PE 로 바꿔 다음 likelihood 를 쓴다.

$\ell_k(s_n) = -\frac{(\mathrm{PE}_{n,k})^2}{2\sigma_k^2}$

score:

$S_k = \log((C_k+1)^\beta + \lambda \mathbb{1}[k=k_{\text{prev}}]) + w_{\text{var}}\ell_k(s_n)$

fresh topic score 는 calibration 기준값으로 둔다.

$S_{K+1} = \log \alpha -\frac{\mathrm{PE}_0^2}{2\sigma_0^2}$

여기서 $\mathrm{PE}_0 = 1 - \text{cos\_threshold}$ 이다. 즉 기존 `cos_threshold` 는 완전히 사라지는 것이 아니라 fresh topic baseline PE 로 재해석된다.

## cos_threshold / hard threshold 흡수

v3.3.2 의 `cos_threshold=0.9` 는 "fresh topic 은 cosine 0.9 수준의 후보처럼 경쟁" 이라는 뜻이었다. v3.3.4 에서는 이를 $\mathrm{PE}_0=0.1$ 의 fresh baseline 으로 바꾼다.

- 기존: $S_{K+1} = \log \alpha + \tau \cdot 0.9$
- 새 식: $S_{K+1} = \log \alpha - 0.1^2/(2\sigma_0^2)$

v3.3.2 의 `pe_threshold=0.5` 는 "cos < 0.5 이면 새 topic 강제" 라는 hard rule 이었다. v3.3.4 에서는 같은 PE 라도 $\sigma_k^2$ 가 작으면 큰 penalty, 크면 작은 penalty 가 되므로 threshold 효과가 likelihood ratio 안으로 들어간다.

## Cold-start 처리

초기 topic 은 $\sigma_k^2$ 추정이 불안정하다. 기본 guard 는 다음과 같다.

- $n_k < n_{\text{var-min}}$ 이면 $\sigma_k^2 = \sigma_0^2$ 사용.
- $n_k \ge n_{\text{var-min}}$ 부터 EMA variance 사용.
- 항상 $\sigma_k^2 \leftarrow \mathrm{clip}(\sigma_k^2, \sigma_{\min}^2, \sigma_{\max}^2)$ 적용.

권장 기본값:

| 이름 | default | 의미 |
|---|---:|---|
| `pe_var_decay` | 0.95 | EMA decay. $\rho=0.05$ |
| `pe_var_min_samples` | 5 | topic별 variance 신뢰 전 최소 sample |
| `pe_var_sigma0_sq` | 0.04 | cold-start scalar PE variance fallback |
| `pe_var_min_sq` | 1e-4 | variance floor |
| `pe_var_max_sq` | 0.25 | variance cap. PE 범위가 대략 $[0,2]$ 라도 cosine-normalized 대화에서는 큰 값 억제 |
| `var_likelihood_weight` | 1.0 | calibrated likelihood scale |

`pe_var_sigma0_sq=0.04` 는 표준편차 0.2 에 해당한다. v3.3.2 best 의 `pe_threshold=0.5` 보다 보수적이며, cold-start 에서 지나친 over-split 을 막기 위한 시작값이다.

## Boundary 결정 로직

기본안은 hard threshold 를 제거하고 MAP / likelihood ratio 만 사용한다.

1. 모든 active topic 과 fresh slot 의 $S_k$ 계산.
2. $k^\* = \arg\max_k S_k$.
3. $k^\* \ne k_{\text{prev}}$ 이면 boundary.
4. $k^\* = K+1$ 이면 새 topic boundary.

이론적으로는 충분하다. fresh slot 이 calibrated likelihood 안에서 경쟁하므로 "PE 가 크면 새 topic" 이 score 자체에 반영된다.

다만 초기 구현에서는 안전장치로 `hard_pe_fallback=False` 를 default 로 두고, 필요 시 v3.3.2 hard rule 을 옵션으로만 켠다. fallback 을 켜도 decision-log 에서는 v3.3.4 핵심 성능으로 보지 않는다.

## SEM 계승 정당화

이 항목은 SEM 에 없는 per-topic 학습을 도입하므로 정당화 부담이 크다.

### SEM2 에 왜 $\sigma_k^2$ 가 없는가

SEM 논문 식 (2) 는 scene dynamics noise 로 $\mathrm{diag}(\beta)$ 를 둔다. SEM2 구현은 event model 별 RNN 을 쓰지만, prediction error covariance 를 topic별로 online 학습하지 않는다. 가능한 해석은 둘이다.

1. **의도적 공통 noise 선택**: 실험 자극이 VAE 압축 영상이고 controlled 환경이라 event별 noise scale 을 별도로 학습할 필요가 작았을 수 있다.
2. **단순 미구현 / 안정성 선택**: topic별 variance 는 작은 event 에서 불안정하고, SEM2 의 목표가 human event segmentation 재현이라 추가 자유도가 필요하지 않았을 수 있다.

Hi-OnTop 에서는 두 해석 중 어느 쪽이든 조심해야 한다. 그래서 v3.3.4 는 default 후보가 아니라 실험 branch 로 두며, min-sample guard / variance floor / cap 을 필수로 둔다.

### cosine 공간에서 topic별 분산 차이가 큰가

직접 관측은 아직 부족하다. 다만 다음 추론 근거가 있다.

- 대화는 좁은 factual thread 와 넓은 social / preference thread 가 섞인다.
- v3.3.2 best HP 에서 multi-topic 은 형성됐지만, hard PE 단독 이득은 제한적이었다.
- cosine substitution 은 Gaussian 정규화항을 버렸기 때문에, topic별 "허용 가능한 PE 폭" 이 score 에 반영되지 않는다.

따라서 v3.3.4 는 "관측 완료된 사실" 이 아니라 "v3.3.2 의 global threshold 한계를 검증하기 위한 보수적 calibration 실험" 으로 둔다.

### sCRP / Bayes 와 충돌 없는가

충돌하지 않는다. sCRP 는 label prior 이고, $\sigma_k^2$ 는 likelihood 의 noise scale 이다. SEM 의 Bayesian 구조는 원래 $P(e_n \mid e_{n-1})P(s_n \mid e_n)$ 의 prior-likelihood 곱이며, variance calibration 은 likelihood 항의 parameterization 변경이다.

다만 절충이 있다.

- SEM2 원형보다 per-topic 자유도가 늘어난다.
- 작은 topic 에서 overfit 위험이 있다.
- 따라서 $\sigma_k^2$ 는 gradient 학습이 아니라 단일 scalar EMA 로 제한하고, $n_{\text{var-min}}$ 전에는 global fallback 을 쓴다.

## 알려진 한계

1. **SEM 계승 부담**: per-topic $\sigma_k^2$ 는 per-topic concentration $\kappa$ 학습과 같은 계열의 calibration 자유도다. 성능 이득이 작으면 제거해야 한다.
2. **작은 topic 불안정**: 짧은 episode 에서 variance 가 작게 추정되면 이후 재방문을 과도하게 거부할 수 있다.
3. **fresh score calibration 난점**: $\sigma_0^2$ 와 $\alpha$ 가 함께 새 topic 빈도를 결정하므로 sweep 공간이 늘어난다.
4. **cosine PE 비정규성**: $\mathrm{PE}$ 분포가 Gaussian 이 아닐 수 있다. $-\mathrm{PE}^2/(2\sigma^2)$ 는 SEM 계승을 위한 근사다.

## 고려 중인 변형

1. **global+topic shrinkage**: $\sigma_{k,\text{eff}}^2 = \eta_k\sigma_k^2 + (1-\eta_k)\sigma_0^2$, $\eta_k = n_k/(n_k+c)$.
2. **robust EMA**: squared error 대신 absolute deviation EMA 를 사용.
3. **per-conversation variance**: topic별이 아니라 conversation 전체 PE variance 로만 calibration. SEM 계승 부담이 더 낮다.
4. **v3.3.3 와 결합**: repeat likelihood 만 $\sigma_k^2$ 로 calibrate 하고 f0 restart 는 별도 $\sigma_{f0,k}^2$ 없이 global fallback 유지.
