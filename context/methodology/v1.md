# v1 — SEM2 본진 (Gaussian likelihood + raw sticky-CRP)

CLI method: `hi-ontop-full-v1`.

## 한 줄

SEM2 의 segmentation 메커니즘을 가장 직접적으로 옮긴 baseline. **Gaussian** likelihood + **raw** sticky-CRP prior.

## Score 식

새 turn `s` 의 topic 배정:

```
ê_n = argmax_k [ log prior(k | e_{n-1}) + log P(s | e=k) ]
```

### prior (sticky-CRP, SEM Eq.1)

```
prior(k) ∝ C_k + λ · 𝟙[e_{n-1}=k]      (k ≤ K)
prior(K+1) ∝ α                          (새 cluster)
```

- `C_k` 가 그대로 곱해짐 → **C_k 가 큰 topic은 prior가 비례적으로 커짐**.

### likelihood (Gaussian)

```
log P(s | e=k) = log N(s ; μ_k, diag(σ_k²))
              = -½ Σ_j [ (s_j - μ_kj)² / σ_kj² + log(2π σ_kj²) ]
```

- Topic 마다 mean `μ_k` 와 per-dim variance `σ_k²` 를 Welford-style online update.
- `n < 3` 동안은 cold-start variance `σ²₀` 사용.

### new cluster (cold start)

```
log P(s | e=K+1) = log N(s ; 0, σ²₀ I)
```

- 평균이 **원점**인 Gaussian. embedding 이 unit sphere 위에 있으므로 항상 점수가 작게 나옴 → 새 topic 생성은 prior `α` 와 `σ²₀` 에 강하게 의존.

## Topic state

- `μ_k` : running mean (Welford)
- `M2_k` : 중심화 제곱합 (variance 계산용)
- `n_k` : 누적 sample 수

코드: `src/hi_ontop/topic.py` 의 `class Topic`.

## Update rule

assignment 후:
1. Welford update on `μ_k`, `M2_k`, `n_k`
2. `C_k += 1`
3. `prev_k = k`

코드: `src/hi_ontop/sem_core.py` 의 `HiOnTopSegmenter.assign`.

## 하이퍼파라미터

| 이름 | default | 의미 |
|---|---|---|
| `α` | 1.0 | sCRP 새 cluster prior |
| `λ` | 10.0 | sCRP stickiness |
| `σ²₀` | 0.01 | Gaussian cold-start variance + new cluster 평균(=0) 분산 |
| `σ²_min` | 1e-6 | variance floor |
| `k_max` | 256 | topic capacity |

## SEM 계승 측면

- ✅ sticky-CRP prior: SEM2 Eq.1 그대로
- ✅ local MAP assignment: SEM의 online MAP 그대로
- ✅ Gaussian likelihood: SEM의 `log_likelihood_next` 와 동일 형태
- ❌ `f0` (event-start initial condition): SEM2 가 별도로 학습/추정하는 분포. v1 은 *origin-centered Gaussian* 으로 단순화.
- ❌ scene dynamics (RNN event model): SEM2 의 prediction error 핵심. v1 에는 없음 — likelihood 가 정적 Gaussian.
- ❌ restart-vs-repeat halving (`prior[k_prev] -= λ/2`): 의도적으로 미포팅. 학습형 dynamics 가 없으면 의미 없다는 판단.

## 알려진 한계 (→ 후속 버전 동기)

1. **Gaussian–unit sphere 부정합**: embedding 이 단위구 위에 있는데 likelihood 는 무한 평면 위 분포. cosine baseline 이 v1 을 이김 → v3.1 에서 bounded cosine 으로 교체.
2. **`σ²₀` 튜닝 민감**: 새 cluster 점수가 `σ²₀` 와 `α` 에 휘둘림. 데이터셋이 바뀌면 재튜닝 필요.
3. **Mega-topic collapse**: raw `C_k` 가 prior 에 그대로 들어가서 큰 topic 이 자기강화. 긴 대화(600-turn 규모)에서 한 topic 이 절반 이상 흡수 → v3.2 의 sub-linear count 동기.
4. **Online MAP irreversibility**: `assign()` 즉시 mean/variance/count 업데이트. 초반 오류 복구 불가.
