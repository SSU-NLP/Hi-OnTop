# v4.3.2-exp — frozen Sentence-T5 + learned NextEmbedHead 가 δ_model 자리 대체

`src/hi_ontop/sem_core_v432_exp.py` · 2026-05-21 · **exp suffix**

## 한 줄

[[v4.1.1]] 의 식 구조 (`δ_eff² = η·δ_adj² + (1−η)·δ_model²`) 그대로
유지하되, **δ_model 의 산출처를 학습형 RNN PE 에서 *frozen Sentence-T5
+ DailyDialog 로 학습한 NextEmbedHead* 의 prediction error 로 교체**.
δ_prev/δ_ctx (mpnet) 는 v4.1.1 그대로.

## 동기 — "진짜 next-utterance prediction" 방어카드 (regressor 버전)

[[v4.3.1]] 에서 DialoGPT-small 의 token-level NLL 로 "다음 발화 *확률*"
을 직접 구현. v4.3.2 는 동일 공격 (prediction-by-production 의
진정성) 에 대한 **embedding-space 답안**:

> "다음 *발화 벡터가 무엇인가*" 를 frozen ST5 위 작은 학습 head 가
> regression 으로 예측. δ_model = 예측 오차 (1 − cos).

### v4.3.1 / CSM 과의 구분 (정체성)

| | CSM (Xing+ 2021; Zhou+ 2022) | v4.3.1 (DialoGPT) | **v4.3.2 (ST5+head)** |
|---|---|---|---|
| 출력 형태 | NSP score (positive/negative) | autoregressive log P | predicted embedding |
| 학습 목적 | discriminative ranking (hinge) | LM pretraining (Reddit) | **continuous regression (cosine)** |
| 학습 데이터 | 자체 NSP pseudo-pair | LM corpus (frozen) | DailyDialog (full train+valid) |
| Frozen 정도 | 학습형 head + encoder finetune | 완전 frozen | encoder frozen, **head 만 학습** |
| Boundary rule | score 자체 사용 | SEM PE channel | SEM PE channel |
| Cosine 사용? | 응집성 정의에 사용 | 0회 | **head 학습 + δ_model 계산에 사용** |

→ v4.3.2 는 *생성적 forward modeling 의 embedding-space 구현*. CSM 처럼
NSP head 학습한다는 점은 닮았으나 **target 이 (positive/negative class)
가 아닌 *실제 다음 발화의 벡터***. 학습 시 negative sample 도 직접 안
보고 cosine regression 만. discriminative → generative 차이.

## 알고리즘 (수학 정의)

```
mpnet 채널 (v4.1.1 그대로):
  δ_prev(t)  = 1 − cos_mpnet(s_topic[t-1], s_topic[t])
  c_topic[t-1] = Σ_{i=1..m_mpnet} ρ^{i-1} · s_topic[t-i]
  δ_ctx(t)   = 1 − cos_mpnet(c_topic[t-1], s_topic[t])
  δ_adj(t)   = a·δ_prev + (1−a)·δ_ctx                     # m_mpnet=2, ρ=0.7, a=0.5

ST5+head 채널 (★ RNN 자리 대체):
  s_st5[t]   = ST5(u_t)                                    # frozen, L2-normalize
  ctx_st5[t] = [s_st5[t-m_LM], ..., s_st5[t-1]]           # left-zero-pad if k<m_LM
  \hat{s}_t  = head_θ(ctx_st5[t])                         # NextEmbedHeadMLP, L2-normalize
  δ_model(t) = 1 − cos_ST5(\hat{s}_t, s_st5[t])           # prediction error

Blend (v4.1.1 식 그대로):
  δ_eff(t)² = η·δ_adj(t)² + (1−η)·δ_model(t)²
  boundary ⇔ δ_eff < δ* = 0.5594                          # mpnet TIAGE-train δ*
```

NextEmbedHead (default = small MLP):

```
input  = concat(ctx_st5) ∈ R^{m_LM · d}      (m_LM=5, d=768 → 3840)
h      = GELU(Linear(input → 1024))
output = Linear(h → d)
\hat{s}_t = L2-normalize(output)
```

학습 (DailyDialog 11k train + 1k valid):
- Loss: ``L = E[1 − cos(\hat{s}_t, s_st5[t])]`` (default).
  옵션 `--nce-weight w` 로 batch-InfoNCE auxiliary 추가 가능 (default w=0).
  codex 권고: collapse 진단 후 조건부 도입.
- Optimizer: AdamW, lr=1e-3, wd=1e-4, linear warmup (5%) → linear decay.
  warmup first-step lr=0 회피 (`(step+1)/warmup`).
- Batch 256, epoch 10, best-by-valid checkpoint.
- Encoder ST5: **frozen 전체 학습 0회**.
- 데이터 source: **원본 `ijcnlp_dailydialog.zip` (yanran.li)**, repo root
  에 두면 `train_next_embed_head.py` 가 자동 탐색 + 재귀 추출
  (`colab_csm_train.ipynb` [2] 셀 패턴). HF `daily_dialog` loading
  script 의 trust_remote_code / format 변동 회피.
- Collapse 진단 (epoch 별 valid metric, codex 권고 2회차 반영):
  - ``mean_baseline_loss`` / ``gain_vs_mean`` — constant-mean predictor 대비

## v4.3.1 와 비교 — scale / 정의 차이

| | v4.3.1 (DialoGPT) | **v4.3.2 (ST5+head)** |
|---|---|---|
| δ_model 정의 | mean per-token NLL | 1 − cos(\\hat{s}_t, s_t) |
| Range (raw) | [0, ∞), 실측 2~8 nats | [0, 2], 실측 ≈ 0.3~0.7 |
| mpnet δ_adj scale 과 일치도 | **불일치** (큰 mismatch) | **자연 일치** (cosine-distance 공통) |
| δ\* re-calibration 필수? | yes (η<1 모두) | likely no (mpnet δ\* 그대로) |
| 학습 0회? | yes (frozen LM) | **no** (NextEmbedHead 학습) |
| Forward cost / turn | LM 1회 (DialoGPT-small) | ST5 1회 + tiny MLP |
| 외부 학습 데이터 | 없음 (frozen pretrain) | **DailyDialog** |

→ v4.3.2 는 scale 일관성이 자연스러워 v4.3.1 의 가장 큰 caveat (raw NLL
scale mismatch) 를 우회. 다만 **head 학습 → out-of-domain
generalization** 이라는 새 위험을 도입.

## SEM 계승 3-step (PASS, conditional)

1. **SEM2 에 있나?** `LinearEvent` 의 learned dynamics slot 자체는 SEM2
   에 존재. v4.3.2 의 head 는 *SEM2 의 LinearEvent 와 가장 직접적으로
   대응* (둘 다 neural net 으로 next-state regression). 차이: SEM2 는
   per-event learning (small adaptive net), v4.3.2 는 corpus-wide
   pretrained ([[v4.2.4]] 의 frozen-DSE 와 같은 도입 방향). 새 mechanism
   아님.
2. **충돌?** 없음. sCRP / Bayes / local-MAP / prior-corrected B0 모두
   변경 0. δ_eff 식 (η blend) 도 v4.1.1 그대로. likelihood `L(δ) =
   −δ²/(2σδ²)` 도 그대로. δ scale 도 cosine-distance 라 mpnet 과 자연
   양립.
3. **decision-log**: 2026-05-21 entry.

### 정직히 보고할 점 (학술 가치)

1. **DailyDialog → TIAGE 도메인 generalization 실패** — 학습 corpus 의
   "다음 발화 평균 방향" 정보가 TIAGE boundary 신호와 *align 안 됨*.
   *task misaligned* (codex 1차 진단 적중).
2. **Regression-to-mean 의 정량 증거** — head 가 학습 분포 평균
   방향으로 수렴 (δ_std ≈ 0.03, plateau). PE channel 정보량 약함.
3. **Calibrated z-blend 가 raw blend 보다 안전** (F1 안 망함, 점진
   회귀). v4.2.3 패턴의 가치 재확인. 단 본질 정보량 부족은 해결 못 함.
4. **CSM (NSP-supervised) 대비 continuous regression 의 한계** —
   v4.3.2 framing 의 학술적 가치는 *부정적 비교*. discriminative
   ranking objective (CSM) 이 보조 channel 로 더 적합할 가능성 시사
   (단 v4.3.2 만의 결과, 직접 비교 별도).
