## 한 줄

[[v4.1.1]] 의 thin subclass. **algorithm 변경 0**. `assign` 결과에
`graded_score = δ_eff / δ*` 의 1-D 연속값을 노출. 신경과학적 framing
(Ben-Yakov & Henson 2018 의 graded hippocampal boundary response 매핑)
의 정량 표현. paper 의 graded boundary 핵심 contribution.

## 동기

v4.1.1 까지 segmenter 출력은 binary `(topic_id, is_boundary)`. 다음
정보가 내부에 있지만 외부 노출 안 됨:

**boundary 의 강도**: `δ_eff < δ*` 의 hard cut 은 binary 결정만 줌.
`δ_eff / δ*` 비율은 **얼마나 강한 boundary 인가** 의 graded scalar.

neuroscience evidence: Ben-Yakov & Henson 2018 ("Event boundaries in
memory") 에서 hippocampal boundary response 가 binary 가 아닌 graded
profile 임을 보임. v4.1.3 의 graded_score 가 이와 직접 매핑.

## 노출되는 attribute / method

```python
seg = HiOnTopSegmenterV413(dim=768, ...)  # V411 의 모든 kwarg 호환
seg.assign(s)  # 동일 return: (topic_id, is_boundary)

# Per-turn readouts (last assign 직후 update)
seg.last_delta_eff       # float, raw δ_eff for chosen topic
seg.last_graded_score    # float, δ_eff / δ* (boundary strength scalar)
seg.last_is_boundary     # bool (parent return 과 동일)

# Full history
seg.history()            # list[dict] per turn: turn, topic_id, is_boundary,
                         # delta_eff, graded_score, topic_count
seg.graded_scores()      # list[float] per-turn graded_score
seg.boundary_strength()  # dict[band → count]: very_weak/weak/normal/strong
```

## Boundary strength bands (Ben-Yakov & Henson 2018 inspired)

| band | graded_score | downstream consumer 권고 |
|---|---|---|
| very_weak | < 0.7 | 보류 (decision deferred) |
| weak | 0.7 ~ 1.0 | repeat 우세 영역 (boundary off) |
| normal | 1.0 ~ 1.3 | 정상 경계 |
| strong | ≥ 1.3 | 즉시 commit |

## SEM 계승 3-step (PASS, trivial)

1. **SEM2 에 있나?** Graded PE 는 SEM2 의 Gaussian residual likelihood
   (`L(δ) = -δ²/(2σδ²)`) 가 본질적으로 graded scalar 인 것의 표면 노출.
   **새 mechanism 도입 0**.
2. **충돌?** 없음. 모든 noted attribute 는 read-only side effect.
   sCRP / Bayes / local-MAP / B0 무변경.
3. **decision-log**: 2026-05-21.

## 데이터 (`outputs/experiments/2026-05-21_v413_demo`)

### Boundary strength distribution

| dataset | n_turns | n_bnd | very_weak | weak | normal | strong |
|---|---:|---:|---:|---:|---:|---:|
| tiage | 1,564 | 431 | 396 | 737 | 406 | 25 |
| dialseg711 | 19,350 | 5,202 | 6,147 | 8,001 | 4,737 | 465 |

→ very_weak + weak 가 non-boundary turn, normal + strong 이 boundary
turn. **graded score 가 binary boundary 와 일관** (strength bands 합산이
실제 boundary count 와 정렬).

### Per-band precision — graded_score 가 calibrated boundary signal ✓

| dataset | very_weak | weak | normal | **strong (≥1.3)** |
|---|---:|---:|---:|---:|
| TIAGE | 0.000 | 0.238 | 0.345 | **0.520** |
| Dialseg711 | 0.000 | 0.129 | 0.383 | **0.800** ⭐ |

→ **strong band precision 이 TIAGE 0.52 / Dialseg711 0.80** — paper 의
"score > 1.3 → 즉시 commit" downstream 정책 정량 근거. very_weak 는
거의 boundary 안 만들고, strong 은 매우 정확.

## 추천 사용

```python
seg = HiOnTopSegmenterV413(dim=768, delta_star=0.5594, ...)
for s in scene_vectors:
    topic_id, is_boundary = seg.assign(s)
    # downstream 이 graded score 활용
    if seg.last_graded_score >= 1.3:
        immediate_commit(s, topic_id)
    elif seg.last_graded_score >= 1.0:
        normal_commit(s, topic_id)
    elif seg.last_graded_score >= 0.7:
        defer_commit(s, topic_id)
    # else: no action
```

## 한계 / 검증 미해결

- **Graded score band 임계값 (0.7 / 1.0 / 1.3) 은 휴리스틱**. Ben-Yakov &
  Henson 의 실험 데이터에서 직접 fit 한 것 아님. SeCom 등 downstream
  consumer 의 실험으로 보정 필요.
- **`very_weak` band 정의 (< 0.7)**: stream start (turn 0) 의 0.0 이
  여기 포함됨. boundary-relevant 통계와 섞이지 않게 caller 측에서
  필터링 권고.
- **F1 / Pk / WD 변화 없음** (algorithm 무변경, output 만 추가). 본
  v4.1.3 의 가치는 정성적 (downstream + 분석).

## 제거된 기능 (2026-05-21)

초기 revision 들에서 시도했지만 제거된 기능:
- `is_reentry` flag (boundary INTO previously-visited topic)
- `same_label_restart` / `cross_topic_reentry` sub-type 분리
- `f0_min_starts=1` default 흡수 (v4.2.1 SEM2-faithful)

**제거 이유**:
- v4.1.1 default (`f0_min_starts=2`) 에선 re-entry mechanism 봉인 →
  `is_reentry` flag 항상 False, 무의미.
- Analysis mode (`f0_min_starts=1`) 활성 시 Score 폭락 (TIAGE -6.9pp,
  Dialseg711 -19.6pp, SuperSeg -10.3pp). 원인: segmenter 가 옛 topic_id
  재사용 → metric 의 label-change count 감소 → recall 폭락.
- 사용자 결정 (2026-05-21): "토픽 회귀 하지마" — re-entry 자체 제거,
  v4.1.3 = pure graded_score output 으로 단순화.

re-entry mechanism 자체는 [[v4.2.1]] 클래스로 ablation 보존 (코드만 보존,
권장 사용 안 함). 측정값 (TIAGE 87% / Dialseg711 94% re-entry rate) 은
2026-05-21 decision-log entry 에 기록 — 향후 재검토 필요 시 참조.
