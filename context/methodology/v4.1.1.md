## 왜 메이저 버전업 (v3.3.10 → v4.1.1)

v3.3.x 는 "SEM2 RNN scene-dynamics 복원" 계열. η-ablation 으로 learned
RNN 이 무용~유해 확정(identity η=1 이 best), v3.3.9 가 prev-cos=SEM2
cold-start identity PE 를 정합 복원하며 사실상 **learned-dynamics 를
버리고 identity + calibrated MAP 로 전환**. v4.1.1 은 그 identity 위에
causal-window 를 얹은 것으로, "RNN scene-dynamics" 라는 v3.3.x 정체성과
질적으로 다른 라인 → 메이저 분리(사용자 결정 2026-05-18). RNN 코드는
`use_rnn` 플래그로 보존(제거 아님), default off(η=1 자동 skip).

## 수식 (v3.3.9 상속 + causal-window)

```
δ_prev(t)  = 1 − cos(s_{t-1}, s_t)                      # SEM2 identity PE
c_{t-1}    = normalize( Σ_{i=1..m} ρ^{i-1} · s_{t-i} )  # causal 맥락(과거만)
δ_ctx(t)   = 1 − cos(c_{t-1}, s_t)
δ_adj(t)   = a·δ_prev + (1−a)·δ_ctx                     # a=ctx_blend_a
δ_eff²     = η·δ_adj² + (1−η)·δ_model²                   # η=eta_prev(기본1)
```

η=1(기본) ⇒ δ_eff = δ_adj, RNN(δ_model) 미사용·자동 skip(`_uses_rnn`
= use_rnn and η<1). repeat-vs-fresh = prior-corrected B0_t (v3.3.9 상속,
δ_eff<δ* hard cut 동치). **δ\* 는 코퍼스/인코더 의존 → 데이터별
재calibration 필요** (TIAGE-train: m2 ρ0.7 a0.5 δ\*0.5594).

## SEM 계승 3-step

1. **있나**: causal-window 는 SEM 의 history-conditioned f(x_{1:n}) 의
   근사 — v3.3.9 가 1-step identity 로 축약한 걸 history 더 쓰는 쪽으로
   되돌림. 새 외부 메커니즘 아님.
2. **충돌**: 없음. boundary 는 여전히 generative PE 증가 시 발생;
   sCRP/Bayes/local MAP/prior-corrected baseline 구조 불변. causal
   (lookahead 없음) → online SEM 정합. RNN 보존(use_rnn).
3. decision-log 2026-05-18 (v3.3.10 도입 + v4.1.1 rename) 참조.
