# v3.3.8 — SEM2-calibrated fresh baseline (`pe_prior`) + non-prev f0 scoring

CLI method: `hi-ontop-full-v3.3.8`. Segmenter `HiOnTopSegmenterV338` (`src/hi_ontop/sem_core_v338.py`, v3.3.7 base). 구현 2026-05-17. 단위테스트 `tests/test_sem_core_v338.py` (7).

## 한 줄

v3.3.7 의 모든 항을 유지하고 두 가지만 변경: (a) fresh/untrained baseline `L0` 를 `cos_threshold` 가 아니라 **`pe_prior`(chance 수준 PE)** 에서 도출 — "untrained 는 chance 보다 잘 설명 못 한다"는 SEM2 *원칙* 을 scalar-PE 세계로 번역(d-차원 Gaussian 포팅의 스케일 불일치 회피). (b) non-prev 기존 topic 을 repeat predictor 가 아닌 **f0-likelihood**(SEM2 `k0≠k_prev`)로 평가.

## 동기

v3.3.7 반증으로 드러난 불변 지배 원인: v3.3.x 가 fresh slot 을 `L0 = −(1−cos\_threshold)²/(2σ0²) = −0.125`(cos_threshold=0.9) 로 둠 = "새 topic 이 들어온 턴을 cos 0.9 로 예측한다"는 비현실 가정. 현실 대화에서 기존 topic 이 다음(하위질문 이동) 턴을 cos≳0.85 로 예측하는 일은 없음 → trained·PE 판정 즉시 fresh 가 거의 항상 승. 이는 HP 값이 아니라 **구조적 SEM2 이탈**(codex 가 2회 "blunt HP" 로 미뤘으나 회귀).

SEM2 의 untrained likelihood 는 "좋은 예측 가정" 이 아니라 *prior predictive*(관측의 무모형 확률). d-차원 Gaussian logpdf 직접 포팅은 Hi-OnTop scalar cosine-PE 와 스케일 충돌. → SEM2 *원칙* 만 번역: untrained = chance, unit 임베딩에서 무정보 예측은 E[cos]≈0 ⇒ PE≈1.

## 수식

$$L_0 = w_{\text{var}}\cdot\Big(-\frac{\texttt{pe\_prior}^2}{2\sigma_0^2}\Big)\qquad(\texttt{pe\_prior}\ \text{이 cos\_threshold 를 대체})$$

active slot $i$ (topic $k$):

- fresh: $\log\mathrm{prior}+L_0$
- 기존 untrained: $\log\mathrm{prior}+L_0$ (v3.3.5 gating)
- 기존 trained ∧ $k=k_{\text{prev}}$: repeat = $\log\mathrm{prior}+w_{\text{var}}(-\mathrm{PE}^2/2\sigma_k^2)$; PE>restart_pe_threshold 면 restart=λ없는 prior + `_f0_loglik`; $S=\max$.
- 기존 trained ∧ $k\ne k_{\text{prev}}$ (**신규, SEM2 `k0≠k_prev`**): $S=\log\mathrm{prior}+\texttt{\_f0\_loglik}(k,s)$ — "이 obs 가 topic k 의 *시작* 처럼 보이나". f0 미seed 면 $L_0$.

`_f0_loglik(k,s)`: f0 centroid 미seed(`f0_count<f0_min_starts`)→`L0`; else `−PE_{f0}²/(2σ_k²)`, `PE_{f0}=1−cos(f0_dir,s)`.

## HP default

| 이름 | default | 의미 |
|---|---:|---|
| `pe_prior` | **1.0** | chance 수준 PE(원칙값). L0 도출. cos_threshold 는 L0 에 더 안 들어감 |
| (v3.3.7 계승) `pe_var_sigma0_sq` | 0.04 | L0 분모 + σ² prior mode |
| `cos_threshold` | 0.9 | **L0 미사용**(legacy; 다른 경로 없음) |

## SEM 계승 정당화

- **왜 SEM2 에 없나**: SEM2 는 untrained=prior predictive(데이터 스케일). Hi-OnTop 의 `cos_threshold` baseline 은 데이터 비결합 임의 상수. v3.3.8 은 SEM2 *원칙*(untrained=chance) 복원. d-차원 Gaussian 직접 포팅 회피는 scalar-PE 구조상 불가피한 *번역* — 이 번역 자체는 SEM2 부재 요소이므로 한계로 명시(아래).
- **충돌 없는가**: non-prev f0 는 SEM2 `sem.py` 의 `k0≠k_prev → log_likelihood_f0` 그대로. f0 는 topic 자기 episode-start centroid.
