# v4.2.5-exp — finetuned BERT-base CSM 이 δ_model (RNN slot) 자리 대체

`src/hi_ontop/sem_core_v425_exp.py` · 2026-05-21 · **exp suffix**

## 한 줄

[[v4.1.1]] 의 식 구조 (`δ_eff² = η·δ_adj² + (1−η)·δ_model²`) 그대로
유지하되, **δ_model 의 산출처를 학습형 RNN PE 에서 NSP-supervised
CSM (Xing & Carenini 2021; `lxing532/Dialogue-Topic-Segmenter`) 의
incoherence probability 로 교체**. δ_prev/δ_ctx (mpnet) 는 v4.1.1 그대로.

## 동기 — CSM 의 discriminative 학습이 v4.3.2 의 regression-to-mean 한계를 회피하는가

[[v4.3.2]] (frozen Sentence-T5 + DailyDialog cosine-regression head) 의
sweep 결과: **single-η mean Score -0.45pp vs v4.1.1 (clear negative)**.
원인 분석: regression-to-mean (δ_std plateau, 모든 sample 의 평균 next
embedding 으로 수렴) + DailyDialog → TIAGE 도메인 generalization 실패.

v4.2.5 의 가설:
- CSM 의 학습 objective = **NSP-style discriminative ranking** (positive
  pair vs random/temporal negative, marginal hinge margin=1)
- → positive/negative 변별 학습이 *generic response collapse 를 원리적
  으로 방지*. discriminative 가 continuous regression 보다 우수할
  가능성.
- 같은 DailyDialog corpus 학습이라 도메인 generalization 은 같은 한계
  가지지만, objective 측면에서 직접 비교 가능.

## 알고리즘 (수학 정의)

```
mpnet 채널 (v4.1.1 그대로):
  δ_prev(t)  = 1 − cos_mpnet(s_topic[t-1], s_topic[t])
  c_topic[t-1] = Σ_{i=1..m} ρ^{i-1} · s_topic[t-i]
  δ_ctx(t)   = 1 − cos_mpnet(c_topic[t-1], s_topic[t])
  δ_adj(t)   = a·δ_prev + (1−a)·δ_ctx                    # m=2, ρ=0.7, a=0.5

CSM 채널 (★ RNN 자리 대체):
  enc(t)     = BERT_tokenizer(u_{t-1}, u_t, max_length=128, truncation=True)
  h_cls(t)   = BERT(enc(t)).last_hidden_state[:, 0, :]   # 768d
  logits(t)  = coherence_decoder(h_cls(t))               # (2,) — [coh, incoh]
  p_coh(t)   = softmax(logits(t))[0]
  δ_model(t) = 1 − p_coh(t)                              # = incoherence prob

Blend — Raw (default, v4.1.1 식):
  δ_eff(t)² = η·δ_adj² + (1−η)·δ_model²
  boundary ⇔ δ_eff < δ* = 0.5594

Blend — Calibrated z-blend (v4.2.3 패턴, --calibrated):
  z_adj   = δ_adj / δ*_adj         # δ*_adj = mpnet 0.5594
  z_model = δ_model / δ*_model     # train 또는 test mean
  z_eff   = √(η·z_adj² + (1−η)·z_model²)
  boundary ⇔ z_eff < 1                                  # internal δ* = 1.0
```

CSM model 구조 (`external/Dialogue-Topic-Segmenter/model_utils.py`):

```python
class CoherenceNet(nn.Module):
    def __init__(self, bert_model, device):
        self.bert = bert_model    # bert-base-uncased
        self.coherence_decoder = nn.Sequential(
            nn.Linear(768, 768),
            nn.ReLU(),
            nn.Dropout(p=0.1),
            nn.Linear(768, 2),
        )
```

## v4.2.4 (DSE) / v4.3.2 (continuous regression) 와 차이

| | [[v4.2.4]] (DSE) | [[v4.3.2]] (TX head) | **v4.2.5 (CSM)** |
|---|---|---|---|
| δ_model 산출 | 1 − cos(s_{t-1}, s_t) DSE cosine | 1 − cos(\\hat{s}_t, s_t) | 1 − softmax(decoder([CLS]))[0] |
| 학습 데이터 | 없음 (frozen DSE-BERT) | DailyDialog cosine regression | DailyDialog NSP triplet |
| 학습 목적 | — | continuous regression (cosine loss) | **discriminative ranking** (marginal hinge) |
| Cosine 사용? | δ 정의에 cosine | δ 정의에 cosine | **0회** (softmax decoder) |
| Output 형태 | similarity | similarity | **probability** |
| Regression-to-mean 위험 | 낮음 (frozen) | 큼 (cosine regression 의 trivial) | **낮음** (positive/negative variance 강제) |

→ v4.2.5 는 **discriminative head** 방향. v4.3.2 의 한계 (continuous
regression 의 mean collapse) 를 회피할 *이론적* 근거. 단 도메인
generalization 한계는 v4.3.2 와 공유.

## 결과 (2026-05-21, raw blend, 2 dataset 부분 sweep)

**Setup**: tiage + dialseg711 test (superseg 사용자 중단으로 미수행),
raw blend (calibrated 미수행), η ∈ {1.0, 0.75, 0.5, 0.25, 0.0}, single
seed. 자세히 → `outputs/experiments/2026-05-21_v425_csm_2ds_raw/REPORT.md`.

### 정직 비교 (single-η mean-best, no test leak)

| | best single η | mean Score | vs v4.1.1 |
|---|---:|---:|---:|
| v4.1.1 (η=1, mpnet only) | — | 0.5286 | — |
| **v4.2.5 (raw, CSM)** | **1.00** | **0.5286** | **−0.0000** |

→ **NEGATIVE** (raw blend). η=1.0 (= CSM 비활성) 이 mean-best 라는 건
정직 비교상 v4.2.5 가 v4.1.1 대비 무이득. η<1 으로 CSM 섞으면 mean
−8.3pp 폭락.

### 데이터셋별 (⚠ test leak — analysis 참고)

| dataset | best η | Score | vs v4.1.1 |
|---|---:|---:|---:|
| tiage | 0.25 / 0.00 | 0.4875 | **+0.0200** |
| dialseg711 | 1.00 | 0.5897 | −0.0000 |

- **tiage**: CSM 단방향 개선. η↓ → Score↑. F1 +8.5pp (0.41→0.50) 가
  주된 ↑동력. Pk/WD 거의 무변 — boundary "갯수" 는 개선되나 "위치"
  는 그대로.
- **dialseg711**: CSM 섞는 순간 **−18.6pp 붕괴** (0.5897 → 0.4040).
  Pk 0.32 → 0.49 (random 수준), WD 0.42 → 0.72. v4.1.1 의 mpnet 채널이
  매우 잘 작동하던 데이터셋에 CSM noise 가 overrule.

### 원인 분석 (잠정)

1. **Raw scale mismatch (가장 유력)** — δ_csm distribution 이 거의
   binary (mean ≈ 0.5, std ≈ 0.5, min 0 max 1 — softmax 의 saturated
   형태). mpnet δ_adj 는 continuous (≈ 0.4-0.7). raw blend 에서 CSM
   의 0/1 spike 가 δ_eff² 를 dominate → mpnet 묻힘.
   → calibrated z-blend (v4.2.3 패턴) 으로 회복 가능성. **미검증.**
2. **Domain shift** — dialseg711 (Wikipedia-style sectioned text) 이
   DailyDialog NSP 학습 corpus 와 매우 멀음. tiage (TV dialog 위주)
   는 더 가까움 → tiage 에서만 도움 되는 현상 부합.
3. **F1 vs Pk/WD 분리** (tiage) — CSM 이 segment count 는 늘리지만
   *어디서* 자를지에 대한 신호는 약함.

### vs v4.3.2 (continuous regression head) 직접 비교

| | v4.3.2 (TX head) | **v4.2.5 (CSM)** |
|---|---:|---:|
| best single-η mean | −0.45pp (NEGATIVE) | −0.00pp (NEGATIVE) |
| best per-dataset (tiage) | 무유의 | **+2.0pp** |
| best per-dataset (dialseg711) | 약한 negative | 큰 negative (−18.6pp) |

**해석**: 두 head 모두 정직 비교 (single-η) 에서 negative. 단:
- v4.2.5 (CSM, discriminative ranking) 는 tiage 에서 *유의미한* 도움
  (v4.3.2 의 무유의 vs +2pp) — gerneric collapse 회피 가설은 *부분
  지지* (in-domain 비슷한 데이터셋 한정).
- v4.2.5 가 도메인 shift 에는 v4.3.2 보다 *더* 취약 (dialseg711 −18.6pp
  vs v4.3.2 의 약한 negative).

**결론**: discriminative 가 *원리적으로* regression-to-mean 을 회피한다
는 가설은 *조건부 지지*. 단 domain shift 에 더 취약한 대가가 있어
single mean-best 기준에선 둘 다 동률 negative. raw blend 한정 결과 —
calibrated 로 scale-mismatch 해소 시 dialseg711 회복 가능성은 미검증.
