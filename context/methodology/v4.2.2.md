# v4.2.2 — scene encoder swap (bge-base-en-v1.5 → aws-ai/dse-bert-base)

`src/hi_ontop/sem_core_v422.py` · 2026-05-20

## 한 줄

v4.1.1 [[v4.1.1]] **알고리즘은 동일**, scene vector encoder 만
`baai/bge-base-en-v1.5` → **`aws-ai/dse-bert-base`** 로 교체. dialogue
domain 에 continued-pretrain 된 DSE-BERT 의 cosine geometry 가
turn-pair similarity (`δ_prev`, `δ_ctx`) 에 더 적합한지 검증.

## 동기

- bge-base 는 general-purpose sentence embedder. dialogue turn (특히
  짧은 발화·response·acknowledgement) 의 cosine 구조가 segmentation
  신호로 최적이라는 보장 없음.
- `aws-ai/dse-bert-base` = AWS AI Labs 의 "Dialogue Sentence Embedder",
  bert-base-uncased 를 dialogue corpora 로 continued-pretrain. lxing532
  CSM (`segment.py`) 의 CM mode 가 backbone 으로 하드코딩한 encoder 와
  동일 — dialogue topic segmentation 에 사실상 표준급 baseline.
- v4.1.1 의 알고리즘 본체는 encoder agnostic (768d normalized 면 OK)
  → 단순 교체로 ablation 가능. δ\* 만 재calibration.

## 무엇이 바뀌나 (= 무엇이 안 바뀌나)

**바뀌는 것** (1줄):
- `s_t = normalize(encoder(turn_t))` 의 `encoder` = DSE-BERT.

**안 바뀌는 것** (v4.1.1 전부 상속):
- δ_prev / δ_ctx / δ_adj / δ_eff 수식
- causal-window (m=3, ρ=0.7, a=0.5)
- sCRP / Bayes / local-MAP / prior-corrected B0
- `f0_min_starts=2` (v4.2.1 의 1 과 조합하려면 명시 kwarg)
- σδ² = c·δ\*² (c=0.0625), pe_prior, pe_var_sigma0_sq …
- RNN 코드 보존 + η=1 default → `_uses_rnn=False` 자동

**⚠ RNN 대체 아님**: v4.1.1 default 가 이미 RNN 미사용. v4.2.2 는
upstream encoder swap 이지 in-segmenter dynamics 변경이 아님. 이 표현
혼동이 decision-log 사유의 절반.

## SEM 계승 3-step (CLAUDE.md SEM 계승 §)

1. **있나**: SEM2 (`nicktfranklin/SEM2`) 의 algorithmic core 는 어떤
   pretrained text embedding 이든 정규화된 vector 면 동작. encoder
   선택은 SEM2 의 알고리즘 자산에 포함되지 않음. → 신규 메커니즘 아님.
2. **충돌**: 없음. sCRP / Bayes / local MAP / prior-corrected baseline
   는 정규화된 768d 임베딩이면 무엇이든 동등하게 동작. δ_eff 계산식
   동일, scale 만 corpus·encoder 따라 이동.
3. **decision-log**: 2026-05-20 entry.

## 검증 미해결

- **encoder 가용성**: Crts proxy (`api.ssunlp.co.kr/v1`) 가
  `aws-ai/dse-bert-base` 슬러그로 embedding 응답하는지 미확인. 첫 호출
  실패시 `HIONTOP_EMBEDDING_BACKEND=local` 로 sentence-transformers fallback.
  로컬 fallback 은 sentence-transformers 가 DSE-BERT 를 정상 mean-pool
  로드하는지 확인 필요 (HF 페이지 README 의 example 코드 따라).
- **δ\* 스케일 차이 추정**: DSE-BERT 가 dialogue 에 tuned 라 인접 발화
  cosine 분포가 더 좁을 가능성 → δ\* 가 더 낮아질 가능성. 정밀 측정
  필요.
- **인접 라인 vs v4.2.1 직교성**: v4.2.1 (`f0_min_starts=1`) 과 동시
  적용 가능 (코드 충돌 없음). f0 + encoder 의 cross-effect 측정은 별
  실험.
