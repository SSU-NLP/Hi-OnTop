## 새 메커니즘

### 1. Restart 발화 보수화 (hysteresis)

기존 v3.3.3-2 의 same-label boundary 조건 `p_rst > ρ_rst` 를 다음 셋으로 강화:

$$\mathrm{boundary}_{same} = (p_{rst} > \rho_{rst}) \;\land\; (p_{rst} - p_{rep}) > m_p \;\land\; \mathrm{age}_{episode} \ge L_{\min}$$

- `restart_p_threshold` (default `0.5`, v3.3.3-2 0.35 → 상향)
- `restart_prob_margin` $m_p$ (default `0.15`): 두 분기 posterior 차이가 noise 위.
- `episode_min_span` $L_{\min}$ (default `4`): 직전 restart 이후 최소 turn 간격 — RNN noise burst 가 곧장 episode 분리로 증폭되는 것을 막음.

`age_{episode}` 는 per-topic counter 로 매 turn 증가, restart 시 0 reset. label change 때도 reset.

### 2. Prototype softening

f0 score 를 top-M `max` 대신 **mean + logmeanexp 가중합**:

$$f0\_sim_k = (1-\gamma)\cos(s, \bar{f0}_k) + \gamma \cdot \mathrm{logmeanexp}_{p\in P_k}\cos(s, p)$$

- $\bar{f0}_k$: prototype list 의 unit-norm running mean (별도 유지)
- $\mathrm{logmeanexp}$: numerically stable softmax-like aggregate (`logmeanexp(x) = log(mean(exp(x)))`).
- `f0_proto_weight` $\gamma$ (default `0.25`): 0 → 순수 mean (가장 안정), 1 → 순수 logmeanexp (다양 prototype 강조). default 0.25 는 mean 우세 + logmeanexp 가 "outlier prototype" 정보 약하게 살림.

prototype list 는 v3.3.3-2 와 동일 (boundary-start embedding top-M, 가득 차면 nearest prototype 과 평균 후 재정규화).

## SEM 계승 정당화

- **Hysteresis (margin + min-span)**: SEM 에 직접 없음. 정당화 (CLAUDE.md SEM 계승 § 3-step):
  1. **SEM 에 왜 없는가**: SEM2 는 boundary 결정이 단일 step 의 likelihood ratio 비교. 단 영상 자극이 controlled 라 RNN noise burst 가 적음. 대화 cosine 환경 + RNN online init 에서는 stochastic boundary noise 가 큼.
  2. **충돌 없음**: posterior odds 는 SEM2 의 `restart > repeat` 정신을 보존. margin / min-span 은 그 비교의 noise threshold 에 해당. sCRP / Bayes / local MAP 와 직교.
  3. **decision-log entry**: 2026-05-10 v3.3.3-3 iter2 결정.

- **Prototype softening (mean+logmeanexp 혼합)**: SEM2 단일 f0 centroid 와 v3.3.3-2 multi-prototype 의 중간. mean 항은 SEM2 와 동일, logmeanexp 는 추가 자유도. multi-prototype 자체 정당화는 v3.3.3-2.md 와 동일 (대화 topic 의 다양한 시작 패턴).

학습 추가 없음 — RNN train_steps 그대로, prototype mean 갱신은 numpy running mean 만. latency 동일.

## 알려진 한계

1. **HP default 임의 선택**: `restart_p_threshold=0.5, prob_margin=0.15, episode_min_span=4, f0_proto_weight=0.25` 는 codex 권장이지만 grid 검증 안 됨. iter2 sanity 후 sweep 필요.
2. **Prototype mean 의 운영**: `_f0_means` 는 단순 running mean (un-normalized, score 시 normalize). prototype list 와 mean 이 따로 갱신되어 일관성 미세 mismatch 가능.
3. **`logmeanexp` 의 cosine domain 사용**: cosine 값은 $[-1, 1]$ 라 `exp(cos)` 의 dynamic range 가 작음. logmeanexp ≈ mean 에 가까워 γ 효과가 약할 가능성 — sweep 시 γ ∈ {0, 0.5, 1.0} 폭으로 test 필요.
