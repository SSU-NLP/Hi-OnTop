# v3.3.3-4 — minimal segmenter (hysteresis restart + episode_id emit)

CLI method: `hi-ontop-full-v3.3.3-4`. Segmenter class: `HiOnTopSegmenterV333_4` (구현 2026-05-11, iter3).

> **참고 (pivot 정리)**: 본 버전은 원래 segmenter 의 minimal 화 + 메모리-시대 retrieval 기계 (atomic retrieval, dormant LTM, importance policy, promotion threshold 등) 통합으로 설계됐다. 2026-05-17 standalone topic-segmenter 전환 시점에 retrieval/promotion/importance 관련 항목은 전부 제거했고, 본 파일에는 **minimal segmenter 알고리즘 + 버전 lineage** 만 남겼다.

## 한 줄

v3.3.3 baseline 위에서 same-label restart 발화를 **hysteresis 로 보수화** 한 minimal segmenter. prototype top-M 은 default 비활성. `(topic_id, episode_id)` 를 atomic 단위로 emit 한다.

## 새 메커니즘

### 1. Segmenter (minimal)

v3.3.3 의 same-label restart 분기 위에 hysteresis 만 얹는다. prototype top-M 은 default 비활성 (`f0_proto_max=1, f0_proto_weight=0.0`).

같은 label 안에서 episode boundary 발화 조건:

$$\mathrm{boundary}_{same} = (p_{rst} > \rho_{rst}) \;\land\; (p_{rst} - p_{rep}) > m_p \;\land\; \mathrm{age}_{episode} \ge L_{\min}$$

defaults: `restart_p_threshold=0.5`, `restart_prob_margin=0.15`, `episode_min_span=8` (v3.3.3-3 의 4 → 상향, RNN noise burst 흡수폭 확장).

`assign(s)` return 이 `(topic_id, is_boundary, episode_id)` **3-tuple** — `(topic_id, episode_id)` 를 atomic 단위로 emit.

## 새 HP

| 이름 | default | 의미 |
|---|---:|---|
| `restart_p_threshold` | 0.5 | same-label restart posterior 임계 |
| `restart_prob_margin` | 0.15 | $p_{rst} - p_{rep}$ 추가 margin |
| `episode_min_span` | 8 | 직전 restart 이후 최소 turn span |
| `f0_proto_max` | 1 | prototype 비활성 (1 = single mean) |
| `f0_proto_weight` | 0.0 | prototype softening 비활성 |

## 영향 범위 — 다른 HP 와의 관계

- **segmenter base**: `alpha`, `lmda`, `tau`, `cos_threshold`, `beta`, `pe_threshold`, `rnn_train_steps`, `rnn_hidden_dim`, `rnn_lr`, `rnn_max_context`, `rnn_min_history` (v3.3.3 상속, 기본 동작 동일).

## SEM 계승 정당화

1. **`(topic, episode)` atomicity** = SEM2 `new_token()` 의 직접 대응. 한 token = 한 episode = 한 prediction-error 가 같이 묶이는 단위. SEM 철학에 충실.
2. **Hysteresis**: v3.3.3-3 동일 (SEM2 `restart > repeat` 의 noise threshold 해석).
