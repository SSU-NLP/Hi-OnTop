## 동기

v3.3.4/5/6 의 σ_k² 는 `pe_var_min_samples=5` 미달 시 cold-start `σ0²=0.04` 고정. topic 이 5 continuation 전에 죽거나 restart 로 transition_count 정체 → 영영 0.04. 정상 주제-연속 PE(0.5~0.6)도 `−0.6²/(2·0.04)≈−4.5` 파국 → fresh(`L0≈−0.125`)에 패배. SEM2 는 prediction_errors 2개부터 `map_variance`(Gelman scaled-inv-χ² posterior mode) 적용(`event_models.py:384,18`) — min-samples gate 자체가 SEM2 이탈.

## 수식

per-topic PE 샘플 버퍼 `_pe_samples[k]`(continuation **및** same-label restart 에서 append, `pe_var_window` FIFO cap). SEM2 prior: `var0 = σ0²·(ν0+2)/ν0` 로 두면 prior mode(n=0)=σ0².

$$\sigma_k^2 = \mathrm{clip}\!\left(\frac{\nu_0\,\mathrm{var}_0 + n\,v_k}{\nu_0 + n + 2},\ \sigma_{\min}^2,\ \sigma_{\max}^2\right)\quad (n\ge2),\qquad \sigma_k^2=\sigma_0^2\ (n<2)$$

$v_k = \mathrm{Var}(\text{PE samples})$ (population, SEM2 `np.var` ddof=0), $n=$ 샘플 수. likelihood/score 식은 v3.3.6 동일(σ_k² 만 이 식으로).

processing C: same-label restart 가 transition_count 를 막아도 σ 샘플은 진척(restart 도 topic k 의 PE 관측).
