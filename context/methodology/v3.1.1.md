# v3.1.1 — Bounded Cosine MAP

CLI method: `hi-ontop-full-v3.1.1`. Segmenter class: `HiOnTopSegmenterV3`.

## 한 줄

Likelihood 를 **Gaussian 에서 bounded cosine 으로 교체**. Topic state 도 centroid 한 점으로 축소 (variance 폐기).

## v1/v2 대비 변경

| 축 | v1/v2 | v3.1.1 |
|---|---|---|
| likelihood | `log N(s; μ_k, diag(σ_k²))` | `τ · cos(s, μ_k)` |
| topic state | `μ_k`, `M2_k` (variance), `n_k` | `μ_k` (unit-norm), `n_k` |
| new cluster score | `log N(s; 0, σ²₀ I)` | `τ · cos_threshold` (상수) |
| `σ²₀` 사용 | yes | **dead** (식에서 빠짐) |
| sticky-CRP prior | raw (β=1.0) | raw (β=1.0) |

## Score 식

```
ê_n = argmax_k [ log prior(k | e_{n-1}) + τ · cos(s, μ_k) ]
```

prior 는 v1 과 동일 sticky-CRP. likelihood 자리에 cosine 이 들어감.

### new cluster

```
score(K+1) = τ · cos_threshold
```

기존 topic `k` 가 새 cluster 를 이기는 조건:
```
cos(s, μ_k) > cos_threshold + (log α − log prior_k) / τ
```

→ `cos_threshold` 는 "기존 topic 으로 흡수할 가치가 있는 cosine 하한선". 0 으로 두면 양수 cos 만 있어도 다 흡수 (mega-topic). 0.7 default 는 "꽤 비슷해야 흡수".

## Topic state

코드: `src/hi_ontop/topic_optimize.py` 의 `class TopicV3`.

- `μ_k` ∈ ℝ^768, *running mean → 매 update 후 unit-norm 으로 재정규화*.
- `n_k` : sample count.
- variance/M2 는 들고 있지 않음. 의도적 제거 ("cosine score has no per-dimension variance term").

## Update rule

assignment 후:
1. `μ_k += (s − μ_k) / n_k`, 그 후 `μ_k /= ||μ_k||` (단위구 위로 다시 투영)
2. `C_k += 1`
3. `prev_k = k`

## 동기

v1 의 두 가지 약점 동시 해결 시도:

1. **Gaussian–단위구 부정합**: cosine 은 단위구 위 자연스러운 거리. embedding 이 normalized 라는 가정과 일치.
2. **likelihood normalization 항이 score 를 평탄화**: v1 Gaussian 의 `Σ log(2π σ²)` 항이 본 거리 항 `(s−μ)²/σ²` 을 잡아먹어, sCRP prior 가 거의 단독으로 결정. cosine 은 정규화 상수 없이 깔끔.

`σ²₀` 의 운명: v3.1.1 식에선 등장하지 않음 → CLI 로 `--sigma0-sq` 를 넘겨도 v3.1.1 은 무시. (sweep script 에 명시적으로 "σ²₀ dead".)

## 하이퍼파라미터

| 이름 | default | 의미 |
|---|---|---|
| `α` | 1.0 | sCRP 새 cluster prior |
| `λ` | 10.0 | sCRP stickiness |
| `τ` | 50.0 | cosine likelihood temperature |
| `cos_threshold` | 0.7 | 새 cluster 점수 baseline (cosine 단위) |
| `k_max` | 256 | topic capacity |

`σ²₀`, `σ²_min` : 식에 없음. CLI 입력은 받지만 segmenter 에 안 전달.

## SEM 계승 측면

- ✅ sticky-CRP prior, local MAP, online update : SEM 형태 유지
- ⚠️ likelihood: SEM 본진은 prediction-error 기반 Gaussian. cosine 은 SEM2 가 *metric substitution* 으로만 허용 (axiomatic 보장 약화). v3.1.1 은 그 substitution 의 가장 단순한 형태.
- ❌ scene dynamics, `f0` : 없음 (v1 과 동일하게 미포팅).

`τ` 는 SEM 에 없는 새 hyperparameter. 단 cosine substitution 자체가 SEM2 에서 명시적으로 허용된 변형이라 "SEM 에 없는 것 추가" 보다는 "허용된 substitution 의 scale 조정" 으로 분류.

## 알려진 한계

1. **Mega-topic 문제 잔존**: prior 에서 `C_k` 가 그대로 곱해짐 → β=1.0 시점에서 v1 의 mega-topic 한계를 해결 못 함. (→ v3.2.1 동기)
2. **`τ` calibration 부재**: `τ` 가 prior vs likelihood 사이 균형을 좌우하는 *숨은 knob*. 데이터셋마다 재튜닝.
3. **`cos_threshold` global 고정**: cosine 분포는 데이터/임베딩 모델/질문 스타일에 따라 다른데 default 가 TopiOCQA-tuned.
4. **Centroid-only**: 분산 정보를 버리니 한 topic 안 sub-cluster 식별 불가. drift 도 누적.
