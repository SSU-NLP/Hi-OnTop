# v4.3.1-exp — DialoGPT-small surprisal 이 δ_model (RNN slot) 자리 대체

`src/hi_ontop/sem_core_v431_exp.py` · 2026-05-21 · **exp suffix**
(promotion 후보지만 δ\* re-calibration + raw-scale 검증 전엔 보류)

## 한 줄

[[v4.1.1]] 의 식 구조 (`δ_eff² = η·δ_adj² + (1−η)·δ_model²`) 그대로
유지하되, **δ_model 의 산출처를 학습형 RNN PE 에서 frozen DialoGPT-small
의 token-level causal surprisal `−log P(u_t | u_{t-m..t-1})` 로 교체**.
δ_prev/δ_ctx (mpnet) 는 v4.1.1 그대로.

## 동기 — "진짜 next-utterance prediction" 의 방어 카드

v4.1.1/v4.2.4 의 mpnet/DSE 채널은 모두 **embedding-space cosine** 으로
δ 를 만든다. 즉 "발화쌍 응집성" 을 직접 측정. 외부 공격 시나리오:

> "Hi-OnTop 의 prediction-by-production 주장은 진짜 다음 발화 예측이
> 아니지 않은가?"

대응 1 (방어 약화 버전): 응집성 모델은 *predictive understanding 의
operationalization* 이라고 해석만 한다 (Pickering & Garrod 2013,
Ryskin & Nieuwland 2023 인용). 생성적 forward modeling 을 구현했다고
**주장하지 않음**.

대응 2 (이 doc, **방어 강화 버전 — v4.3.1**): "그렇다면 진짜로 다음
발화 확률을 계산하자". DialoGPT-small (Zhang et al. 2020) 의 causal
LM 으로 `−log P(u_t | u_{<t})` 를 직접 산출. 이 surprisal 을 SEM2 의
`LinearEvent` 동역학 slot 에 frozen-f 형태로 끼워넣음 ([[v4.2.4]] 의 DSE
대체 패턴과 동형).

## CSM (Xing & Carenini 2021; Zhou+ 2022) 과의 구분

- **CSM 류 (NSP-supervised)**: encoder 위에 next-sentence-prediction
  head 를 *학습* 시켜 응집성 score 를 만든 후, 그 score 자체를 boundary
  decision rule 에 직접 사용.
- **v4.3.1**: frozen pretrained dialogue-LM 의 zero-shot surprisal 을
  SEM2 의 dynamics slot 안 *PE channel* 로 주입. boundary 는 sCRP +
  local-MAP + B0 prior-corrected 식이 결정. δ 정의에 cosine 미사용
  (LM surprisal 만).

→ "다음 발화 확률을 직접 쓰지만 학습 안 함, 게다가 SEM 의 PE channel
스토리 안에 자연 흡수" 가 v4.3.1 의 정체성. CSM 의 흡수도 아니고, 단순
응집성 score 의 재포장도 아님.

## 알고리즘 (수학 정의)

```
mpnet 채널 (v4.1.1 그대로):
  δ_prev(t)  = 1 − cos_mpnet(s_topic[t-1], s_topic[t])
  c_topic[t-1] = Σ_{i=1..m} ρ^{i-1} · s_topic[t-i]
  δ_ctx(t)   = 1 − cos_mpnet(c_topic[t-1], s_topic[t])
  δ_adj(t)   = a·δ_prev + (1−a)·δ_ctx                     # m=2, ρ=0.7, a=0.5

LM channel (★ RNN 자리 대체):
  context_t  = u_{max(0, t-m_LM)..t-1}     (causal window m_LM=5)
  nll_t      = mean_{w ∈ tokens(u_t)}  −log P_LM(w | context_t, u_t<w)
  δ_model(t) = nll_t                        (raw mean-token NLL, no normalization)

Blend (v4.1.1 식 그대로):
  δ_eff(t)² = η·δ_adj(t)² + (1−η)·δ_model(t)²
  boundary ⇔ δ_eff < δ* = 0.5594                          # mpnet TIAGE-train δ*
```

NLL 산출 포맷 — **DialoGPT 학습 분포 보존**:
- `context_text = "<|endoftext|>".join(u_{t-m..t-1}) + "<|endoftext|>"`
- `target_text = u_t + "<|endoftext|>"`
- HF CausalLM forward 의 label mask 로 target 위치 token 만 loss 에 반영
- ⚠ transformers 의 `apply_chat_template` (ChatML 등) 은 학습 분포 밖
  포맷 삽입 위험 → **raw EOS-concat** 사용 (precompute script 의
  선택). 사용자 예시 snippet 은 API 형태 참고용이며, 본 구현은 raw
  포맷으로 진행. (대체 포맷은 추후 ablation 후보.)

⚠ **δ_adj 와 δ_model 의 raw scale 이 매우 다름**: mpnet δ ≈ 0.4~0.6,
DialoGPT mean-token NLL ≈ 2~8 (nats/token). η blend 가 raw 로 일어나서
η<1 에서 δ_eff 가 NLL 항으로 급팽창 → 같은 δ\* 에서 boundary 거의 항상
트리거 = **과분절** 위험. [[v4.2.4]] (DSE δ ≈ 0.3~0.5) 와 정반대 방향의
scale mismatch.

→ 1차 sweep 은 η ∈ {1.0, 0.99, 0.95, 0.9, 0.75, 0.5} 형태로 η→1 쪽으로
조밀하게 잡는다. δ\* 재calibration 은 후속 (`calibrate_v431_*`).

## [[v4.2.4]] 와의 차이 (왜 또 다른 변형)

| | v4.2.4-exp (DSE) | **v4.3.1-exp (DialoGPT)** |
|---|---|---|
| δ_model 의 정보원 | DSE-BERT sentence embedding cosine | DialoGPT-small token-level surprisal |
| 측정 대상 | "u_t 가 이전 발화와 얼마나 응집적인가" (cosine) | "u_t 가 이전 발화 *다음에 올 확률*" (autoregressive P) |
| 형식적 형태 | δ = 1 − cos (∈ [0, 2], 실측 0.3~0.5) | δ = mean-token NLL (∈ [0, ∞), 실측 2~8) |
| **방어 storyline** | 응집성 model 재해석 | 진짜 next-utterance prediction 의 직접 구현 |
| Cosine 사용? | 응집성 정의에 cosine 사용 | **cosine 0회** (LM forward 만) |
| Scale mismatch 방향 | δ_model < δ_adj → 과합병 경향 | δ_model > δ_adj → 과분절 경향 |
| 추가 forward cost | encoder 1회/turn (가벼움) | LM 1회/turn (DialoGPT-small 117M, CPU 가능) |

→ v4.3.1 은 **mechanism interpretation 의 옵션**으로 v4.2.4 와 병렬
관계. 둘 중 어느 것이 SEM2 의 frozen-f 대체로 적합한지는 정성/정량
비교 후속.

## SEM 계승 3-step (PASS, conditional)

1. **SEM2 에 있나?** `LinearEvent` 의 learned dynamics slot 자체는 SEM2
   에 존재. v4.1.1 가 그 자리에 RNN 을 두었고, v4.2.4 가 frozen DSE
   cosine 으로 교체. v4.3.1 은 **같은 slot 의 또 다른 frozen 대체**
   (LM surprisal). 새 mechanism slot 도입이 아니라 기존 slot 의 구현
   교체.
2. **충돌?** 없음. sCRP / Bayes / local-MAP / prior-corrected B0 모두
   변경 0. δ_eff 식 (η blend) 도 v4.1.1 그대로. likelihood `L(δ) =
   −δ²/(2σδ²)` 도 그대로 — 단 δ scale 의 적합성은 raw NLL 의 큰 값
   때문에 caveat (재calibration 필요).
3. **decision-log**: 2026-05-21 entry.

⚠ Framing 가이드 (외부 발표 / 논문 시):
- "DialoGPT 의 next-utterance probability 를 SEM2 dynamics slot 의
  frozen-f 로 사용." 이라고 *기술적으로* 기술.
- "prediction-by-production 의 *생성적* 구현" 이라는 강한 주장은 *피한다*
  — DialoGPT 는 zero-shot 으로 segmentation-friendly 한 generation 을
  훈련받지 않았다. 단지 그 surprisal 이 boundary 정보를 담는다는 *경험
  가설* 만 검증한다.
- CSM 과의 차이는 (a) zero-shot frozen, (b) SEM PE channel 흡수, (c)
  cosine 미사용 의 세 축으로 명시.
- Pickering & Garrod 2013 / Ryskin & Nieuwland 2023 은 **개념 인용만**,
  성능 근거 금지.

## 운영 (use_rnn 강제 False)

- `super().__init__(use_rnn=False, ...)` → parent 의 RNN compute / training 회피.
- `_uses_rnn()` 은 항상 False 반환.
- `_delta_eff` override → cached LM NLL 을 `d_model` 로 사용.
- Caller 는 `assign_pair(s_topic, nll_t)` 사용. NLL 은 **precompute
  script** 산물 (`outputs/runs/_misc/sds_nll_*_*.pkl`) 에서 dialog 별로
  넘김. 단일 벡터 `assign` 은 `NotImplementedError`.
- 첫 turn (no prior context) 은 `nll_t = 0.0` 으로 처리. parent 의
  stream-start fallback (`_delta_prev is None`) 과 자연 정합.

## 한계 / 검증 미해결

- **Raw NLL scale mismatch** (가장 큰 caveat) — η<1 에서 δ_eff 가
  surprisal 항에 급팽창. δ\* 재calibration 미수행.
- **DialoGPT-small (117M, Reddit)** 의 도메인 mismatch — TIAGE 자연
  대화 vs Dialseg711 정형 vs SuperDialseg gov FAQ. surprisal 절대값이
  dataset 마다 다를 가능성.
- **EOS-concat vs ChatML 포맷 비교 미수행** (학습 분포 보존을 명목적
  근거로 사용 중).
- **Causal context window m_LM=5** — m sweep 미수행.
- **모델 크기 / 다른 LM 비교 (T5-small, OPT-125M 등) 미수행** — DialoGPT
  의 특수성 (대화 학습) 이 segmentation 에 유리한지 검증 안 됨.
- **NLL aggregate = mean-token** — sum-token / median / quantile 등
  alternative 미비교.
- **Single seed, single LM** — variance 미측정.
- **TIAGE-test 는 in-domain 측정 가능성** (calibration source 가
  TIAGE-train δ\*). v4.1.1.md 와 같은 disclosure 적용.
- **NLL=0 의 첫 turn fallback** 이 다른 turn 의 distribution 과 어울리는지
  검증 안 됨 (η<1 일 때 첫 turn 이 항상 boundary 강제될 수도 있음).
