# v3.3.5 — SEM2 `f_is_trained` cold-start gating 복원

CLI method: `hi-ontop-full-v3.3.5`. Segmenter class: `HiOnTopSegmenterV335` (`src/hi_ontop/sem_core_v335.py`, 구현 2026-05-17). 단위테스트 `tests/test_sem_core_v335.py` (6).

## 한 줄

v3.3.4 의 per-topic variance likelihood 를 그대로 두되, **아직 within-event transition 을 한 번도 관측하지 않은 topic** 은 centroid PE 로 처벌하지 않고 fresh slot 과 **동일한 baseline 상수 `L0`** 를 부여한다(SEM2 `f_is_trained` gating 복원). young topic 생존은 sCRP λ stickiness 가 결정 → chicken-and-egg 해소. v3.3.3 의 f0/restart 분기도 함께 유지.

## 동기 (chicken-and-egg)

v3.3.4 는 *모든* 기존 topic 을 centroid/RNN PE 로 평가했다. 1턴짜리 topic 의 centroid 는 그 1턴 임베딩뿐이라 다음(하위질문 이동) 턴 예측이 cos 0.4~0.55 → PE 0.5~0.6 → `−PE²/(2σ0²)≈−4` 파국. fresh slot 은 상수 `−0.125`. 따라서 young topic 이 *나쁜 예측으로 처벌* 받아 fresh 에 패배, 1턴에 사망. "좋은 예측엔 누적, 누적엔 생존, 생존엔 좋은 예측" 순환. v3.3.4 의 σ_k² 보정은 `pe_var_min_samples=5` 미달로 영영 미발동.

SEM2(`SEM/sem/event_models.py`)는 이 순환이 없다: `log_likelihood_next`/`log_likelihood_f0` 가 `f_is_trained=False` 면 **고정 prior 상수** 반환(예측오차 미사용). `f_is_trained` 는 within-event `update(x_prev,x_curr)` 1회(= transition; `update_f0` 시작점은 아님) 후 True. 따라서 brand-new cluster 와 untrained young `k_prev` 가 *동일* likelihood → sCRP prior 단독 결정 → `k_prev` 의 +λ 가 young topic 을 생존시켜 첫 transition 관측 → trained.

## state (per-topic 추가)

| 필드 | 의미 |
|---|---|
| `_transition_count[k]` | within-event continuation(= `k==prev_k` ∧ not boundary ∧ prev_k≠None) 횟수. boundary/restart/episode-start 는 증가 안 함 |
| (v3.3.4 계승) `_pe_mean/_pe_var/_pe_var_count[k]` | per-topic cosine PE EMA (trained 후 σ_k²) |
| (v3.3.3 계승) `_f0_centroids/_f0_counts[k]` | episode-start centroid (restart 분기용) |

## 수식

`f_trained_k := transition_count_k ≥ min_transitions_for_pe` (기본 1).

baseline 상수 (fresh = untrained 공통):

$$L_0 = w_{\text{var}}\cdot\Big(-\frac{\mathrm{PE}_0^2}{2\sigma_0^2}\Big),\quad \mathrm{PE}_0 = 1-\text{cos\_threshold},\ \sigma_0^2=\texttt{pe\_var\_sigma0\_sq}$$

active slot $i$ (topic $k$):

- fresh slot: $S = \log\mathrm{prior} + L_0$
- 기존 **untrained**: $S = \log\mathrm{prior} + L_0$  (동일 상수, PE 미사용 → likelihood 동률, prior(λ) 가 결정)
- 기존 **trained**: $S = \log\mathrm{prior} + w_{\text{var}}\big(-\mathrm{PE}_k^2/(2\sigma_k^2)\big)$  (v3.3.4 식)
- $k=k_{\text{prev}}$ ∧ trained ∧ $\mathrm{PE}_{\text{repeat}}>\texttt{restart\_pe\_threshold}$: v3.3.3 same-label restart — restart 는 f0 likelihood + λ 없는 prior; $S=\max(\text{repeat},\text{restart})$, restart 승 → boundary(같은 topic_id 유지).

`transition_count` 는 continuation 에서만 증가(SEM2: `f_is_trained` 는 첫 within-event update 후 True). restart/boundary 는 f0 갱신만.

## HP default

| 이름 | default | 의미 |
|---|---:|---|
| `min_transitions_for_pe` | 1 | f_is_trained gate (rnn_min_history 와 **분리**) |
| (v3.3.4 계승) `pe_var_sigma0_sq` | 0.04 | cold-start σ², L0 의 분모 |
| `cos_threshold` | 0.9 | L0 의 PE₀=1−cos_threshold |
| `restart_pe_threshold` | 0.5 | v3.3.3 restart gate |
| `f0_min_starts` | 2 | f0 centroid seed 최소 |
