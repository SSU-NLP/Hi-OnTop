# v3.3.9 — adjacent-utterance PE 복원 (prior-corrected fresh baseline)

`src/hi_ontop/sem_core_v339.py` · 2026-05-18

## 한 줄

같은 인코더·eval 에서 1줄 prev-cos baseline(F1≈0.44)이 SEM 전 변형
(F1 0.25~0.36)을 압도한 진단을 받아, **prev-cos = SEM2 cold-start

## 동기 (codex 2026-05-17~18 위임 2건)

- 진단: 인코더·eval 무관(3 인코더 prev-cos 모두 F1 0.43~0.44, 우리
  gt_shifts+F1 동일). 근본원인 = SEM 의 **fresh/untrained baseline
  `L0` 오보정 + scalar cosine-PE σ² 포화**. v3.3.5 `L0=−0.125`
  (cos_threshold 가정) → 과분절, v3.3.8 `L0=−12.5`(pe_prior=1) →
  collapse. 같은 의미 연속 발화도 PE≈0.55~0.6 → log-lik −3.8~−4.5 로
  포화되어 fresh 가 항상 이기거나(과분절) 절대 못 이김(collapse).
- prev-cos `δ=1−cos(s_{t-1},s)` 는 SEM2 untrained `predict_next`
  = identity/persistence(`f(x)=x_prev`)의 cosine PE 그 자체. SEM 밖
  heuristic 이 아니라 SEM PE 의 가장 단순한 특수형 → 복원이 정답
  (codex (A)). CLAUDE.md cosine 금지는 *retrieval* 한정 — segmentation
  PE 는 본질적으로 인접 의미거리이므로 위반 아님(decision-log 2026-05-18).

## 수식

```
δ_prev(t)   = 1 − cos(s_{t-1}, s_t)            # SEM2 identity-dynamics PE
δ_model,k   = topic_k.prediction_error(s_t)    # learned/persistence f
δ_eff,k²    = η·δ_prev² + (1−η)·δ_model²        # η = eta_prev (기본 1.0)

Lδ(d)       = var_w · ( −d² / (2·σδ²) )         # σδ² 고정 = c·δ*²
σδ²         = sigma_delta_c · δ*²               # c 기본 1/16 = 0.0625

repeat(k=prev_k) score   = log P_prev + Lδ(δ_eff)        # trained·untrained 공통
fresh-slot score         = log P_new  + B0_t
B0_t (prev-corrected)    = Lδ(δ*) + log( P_prev / P_new )
```

핵심 동치 (codex 2026-05-18 도출): `_scores` 가 fresh slot 에
`log P_new`, repeat 에 `log P_prev` 를 더하므로

```
repeat > fresh
⟺ log P_prev + Lδ(δ_eff) > log P_new + Lδ(δ*) + log(P_prev/P_new)
⟺ Lδ(δ_eff) > Lδ(δ*)  ⟺  δ_eff < δ*      (prior 항 완전 상쇄, 매 turn)
```

→ SEM-MAP 의 prev-vs-fresh 결정이 **모든 turn 에서 prev-cos hard cut
`δ_eff < δ*` 와 정확히 동치**. v3.3.9-pre 의 회귀 원인이었던 고정 r0
prior mismatch(`P_prev/α` 가 turn 진행에 커져 threshold 가 밀려
과병합)를 prior-correction 으로 제거.

`δ*` 는 **TIAGE train split** prev-cos best 에서 추정(0.5557 @
cos_th 0.4443, F1 0.437, n_conv=300) — **test 미접촉, leakage 없음**.
f0 / 비-prev 재진입 path 는 prior-free `_l0()=Lδ(δ*)`(r0=1) 사용.

## HP default

`alpha=1.0 · lmda=10.0 · eta_prev=1.0 · delta_star=0.5557 ·
sigma_delta_c=0.0625 (σδ²≈0.0193) · sigma_delta_sq=None(=c·δ*²)`.
나머지(pe_var_*, restart, f0, rnn_*)는 v3.3.8 default 계승.
`pe_prior`·`cos_threshold` 는 L0 에서 폐기(legacy 인자만 잔존).

## SEM 계승 정당화 (CLAUDE.md 3-step)

1. **SEM 에 있나**: 있다. prev-cos = SEM2 untrained `predict_next`
   identity dynamics 의 cosine PE. 새 메커니즘 도입이 아니라 SEM2
   cold-start 거동의 *복원* (v3.3.5~8 이 L0 오보정으로 이를 못 냄).
2. **충돌 없음**: sCRP/Bayes/local MAP 구조 유지 — prior 는 그대로
   곱해지고 B0_t 가 prior 를 *상쇄*만 함(제거 아님). η<1 이면 learned
   f 와 자연 혼합(SEM dynamics 계승 유지, RNN 폐기 아님).
3. decision-log 2026-05-18 entry 에 근거+날짜 append.
